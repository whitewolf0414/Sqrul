# Support Guidelines

Thank you for using SQRUL! We want to support you as best we can.

## Getting Help

If you run into issues, please use the following resources:

1. **GitHub Issues:** Search through open issues or open a new one if your bug is reproducible.
2. **Discussions:** Use GitHub Discussions for general questions, architecture suggestions, or design talks.
3. **Rust community:** For generic questions regarding async runtime or Cargo dependencies, consider visiting the official Rust user forum.
